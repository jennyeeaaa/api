Title: API-CALL

Working on the API Call project helped me understand how applications communicate with each other through APIs. By using methods like GET, POST, PUT, PATCH, and DELETE, I learned how to retrieve, add, update, and remove data. It gave me a clearer idea of how data is managed in real-world systems and Also I encountered some challenges during the setup and testing process, This project improved my problem-solving skills and gave me more confidence in working with APIs.
